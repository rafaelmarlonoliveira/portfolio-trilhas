# Portfólio - Programa Trilhas

## Como usar
1. Coloque sua foto na pasta `img` com o nome `foto.jpg`.
2. Abra o arquivo `index.html` no navegador para visualizar o portfólio.
3. Troque os links do GitHub, LinkedIn e certificados pelos seus links reais.
4. Depois, crie um repositório público no GitHub e envie todos os arquivos.

## Tecnologias
- HTML5
- CSS3
- JavaScript básico
Portfólio desenvolvido durante o Programa Trilhas.
